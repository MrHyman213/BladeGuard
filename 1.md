AdminBot:
1. При одобрении заявки, модератору приходит сообщение-подтверждение о том, что в систему будут добавлены новые альтернативы (если таковые имеются)
Пример: 
```
┌─────────────────────────────────────┐
│  🔄 Альтернативы добавлены:         │
│  • Victorinox / Climber             │
│  • Victorinox / Huntsman            │
│                                     │
│  Завершить добавление?              │
│                                     │
│  [✅ Да, завершить] [❌ Отмена]     │
└─────────────────────────────────────┘
```

**После нажатия `[✅ Да, завершить]`:**
1. Проверяются транзитивные альтернативы
2. Если найдены — предлагается добавить
3. Пользователь получает уведомление
4. Если бренд новый — обновляются все главные меню

**Транзитивные альтернативы:**
```
┌─────────────────────────────────────┐
│  🔄 Найдены транзитивные            │
│  альтернативы:                      │
│  • Victorinox / Climber             │
│  • Victorinox / Huntsman            │
│                                     │
│  Добавить к сертификату #123?       │
│                                     │
│  [✅ Да] [❌ Нет]                    │
└─────────────────────────────────────┘
```

KnifeBot: 
1. Отправил заявку, администратор её принял. После принятия, в главном меню редактируется список брендов.
Вид меню: 
```
┌─────────────────────────────────────┐
│  Blade Guardian                     │
│                                     │
│  [Victorinox] [Boker] [Cold Steel]  │
│  [Benchmade] [Spyderco] [Kershaw]   │
│  ... (ещё 8 рядов) ...              │
│                                     │
│  [🔪 Ножи без бренда]               │
│                                     │
│  [⬅️] [1/5] [➡️]                   │
│  [🔍 Поиск] [📤 Загрузить]          │
└─────────────────────────────────────┘
```
```
Пользователь нажимает: [Victorinox]
```

**Что происходит:**
- Удаляются все сообщения кроме главного меню
- Загружаются модели бренда из `knives`
- Отправляется список моделей (до 20 на странице)

**Вид списка:**
```
┌─────────────────────────────────────┐
│  🏷️ Victorinox                      │
│  Всего: 45 моделей                  │
│                                     │
│  [Swiss Army Knife] [Classic SD]    │
│  [Climber] [Huntsman] [Ranger]      │
│  ... (ещё 8 рядов) ...              │
│                                     │
│  [⬅️] [1/3] [➡️]                   │
│  [🔍 Поиск] [🔙 К брендам]          │
└─────────────────────────────────────┘
```
