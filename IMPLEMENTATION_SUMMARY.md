## Технические детали

### Новые классы:
- `KnifeBotRedesigned.java` - новый пользовательский бот с полным UI
- `BrandService.java` - управление брендами
- `PendingAlternativeService.java` - временные альтернативы
- `PhotoHistoryService.java` - история замен фото
- `BotSettingsService.java` - настройки бота

### Обновленные классы:
- `AdminBot.java` - добавлены обработчики для pending alternatives, транзитивных альтернатив, замены фото
- `SubmissionService.java` - методы для работы с альтернативами
- `ConversationState.java` - новые поля для навигации и формы

### Ключевые особенности:
- Циклическая пагинация (последняя страница → первая)
- Управление состоянием через ConversationStateManager
- Удаление всех сообщений кроме главного меню
- Inline-клавиатуры для всех действий
- Автоматическое обновление форм через editMessageReplyMarkup
