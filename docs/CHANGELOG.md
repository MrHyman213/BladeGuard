# Changelog

## [1.1.0] - 2026-02-26

### Добавлено

#### Система заявок
- Пользователи могут создавать заявки на добавление сертификатов
- Загрузка фото в папку `/certificates/offer` на Яндекс.Диске
- Возможность добавления описания к фото (опционально)
- Три способа создания заявки:
  - Фото с подписью (caption)
  - Фото, затем текстовое описание
  - Фото без описания (команда /skip)

#### Функционал администратора
- Просмотр списка заявок на рассмотрении (`/pending`)
- Детальный просмотр заявки с фото (`/view <id>`)
- Добавление/редактирование описания администратора (`/desc <id>`)
- Добавление тегов к заявкам (`/tags <id> <тег1,тег2>`)
- Одобрение заявок (`/approve <id>`)
- Отклонение заявок (`/reject <id>`)

#### База данных
- Таблица `submissions` для хранения заявок
- Таблица `tags` для тегов
- Таблица `submission_tags` для связи заявок и тегов
- Таблица `certificates` для одобренных сертификатов
- Таблица `certificate_tags` для связи сертификатов и тегов
- Миграции через Liquibase

#### Новые классы
- `entity/Tag.java` - сущность тега
- `entity/Submission.java` - сущность заявки
- `entity/Certificate.java` - сущность сертификата
- `repository/TagRepository.java` - репозиторий тегов
- `repository/SubmissionRepository.java` - репозиторий заявок
- `repository/CertificateRepository.java` - репозиторий сертификатов
- `service/SubmissionService.java` - сервис для работы с заявками

#### Документация
- `SUBMISSION_FEATURE.md` - подробное описание функционала заявок
- `DEPLOYMENT.md` - инструкция по развертыванию
- `EXAMPLES.md` - примеры использования
- `DATABASE_SCHEMA.md` - схема базы данных
- `sql/queries.sql` - полезные SQL запросы

### Изменено

#### YandexDiskService
- Добавлен метод `uploadPhotoToOffer()` для загрузки в папку offer
- Рефакторинг метода `ensureFolderExists()` для поддержки разных папок

#### KnifeBot
- Добавлена команда `/submit` для создания заявок
- Добавлена команда `/skip` для пропуска описания
- Добавлена обработка фото с созданием заявок
- Добавлен контекст для отслеживания состояния пользователя

#### AdminBot
- Расширен список команд для работы с заявками
- Добавлена обработка контекста для многошаговых операций
- Улучшено форматирование сообщений

#### pom.xml
- Добавлена зависимость `spring-boot-starter-data-jpa`
- Добавлена зависимость `postgresql`
- Добавлена зависимость `liquibase-core`

#### application.properties
- Добавлены настройки подключения к PostgreSQL
- Добавлены настройки Liquibase

#### docker-compose.yml
- Добавлены переменные окружения для админ-бота

#### README.md
- Обновлено описание функционала
- Обновлен список команд
- Добавлена ссылка на документацию
