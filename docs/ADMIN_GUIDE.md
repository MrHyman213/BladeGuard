# Blade Guardian - Руководство администратора

## Начало работы

1. Найдите админ-бота в Telegram: `@YourAdminBotUsername`
2. Нажмите `/start`
3. Откроется главное меню с кнопками

## Главное меню

Доступные действия:
- **📋 Ожидающие заявки** - просмотр заявок на модерацию
- **✅ Одобренные** - просмотр одобренных сертификатов
- **📤 Загрузить фото** - загрузка фото на Yandex Disk
- **🗑️ Очистить все** - удаление всех заявок (с подтверждением)

## Модерация заявок

### Просмотр ожидающих заявок

1. Нажмите **📋 Ожидающие заявки** или `/pending`
2. Откроется список заявок с пагинацией
3. Для каждой заявки показано:
   - ID заявки
   - Пользователь (@username)
   - Дата создания
   - Кнопка "Просмотр"

### Просмотр деталей заявки

1. Нажмите **👁️ Просмотр** на заявке
2. Откроется форма с:
   - Фото сертификата
   - Информацией о пользователе и дате
   - Редактируемыми полями

### Редактирование полей

Нажмите на кнопку поля для изменения:
- **🔪 Название** - изменить название модели
- **🏷️ Бренд** - изменить бренд
- **🔢 Индекс** - изменить индекс
- **🔄 Альтернативные модели** - изменить список (через запятую)

После нажатия:
1. Введите новое значение
2. Сообщение автоматически удалится
3. Форма обновится с новым значением

### Pending Alternatives (Ожидающие альтернативы)

Если пользователь добавил альтернативы, они отображаются в форме:

**⚠️ Ожидающие альтернативы ⚠️**
- **❌ Бренд - Название** - удалить эту альтернативу
- **✅ Принять все** - автоматически найти и создать связи
- **🗑️ Удалить все** - удалить все альтернативы

#### Принятие альтернатив

При нажатии **✅ Принять все**:
1. Система ищет каждую альтернативу в базе
2. Если найдена - создается связь
3. Если не найдена - показывается предупреждение
4. Отображается отчет:
   ```
   📊 Результаты обработки:
   ✅ Добавлено: Victorinox - Classic SD
   ❌ Не найдено: Unknown - Model X
   
   Принято: 1
   Не найдено: 1
   ```

### Транзитивные альтернативы

При одобрении заявки с альтернативами система автоматически проверяет транзитивные связи.

**Пример:**
- Нож A имеет альтернативу B
- Нож B имеет альтернативы C и D
- Система предложит добавить C и D к ножу A

**Предложение:**
```
🔄 Найдены транзитивные альтернативы:
• Victorinox - Climber
• Victorinox - Huntsman

Добавить их к сертификату #123?
```

Кнопки:
- **✅ Да** - добавить все транзитивные альтернативы
- **❌ Нет** - пропустить

### Одобрение заявки

1. Проверьте и отредактируйте поля
2. Обработайте pending alternatives
3. Нажмите **✅ Одобрить**
4. Система:
   - Переместит фото в `app:/certificates/`
   - Создаст связи с альтернативами
   - Проверит транзитивные альтернативы
   - Уведомит пользователя
5. Вы вернетесь в главное меню

### Отклонение заявки

1. Нажмите **❌ Отклонить**
2. Система:
   - Удалит фото из `app:/offers/`
   - Удалит заявку из базы
   - Уведомит пользователя
3. Вы вернетесь в главное меню

### Отмена модерации

Нажмите **🔙 Отмена** для возврата к списку заявок без изменений.

## Управление одобренными сертификатами

### Просмотр одобренных

1. Нажмите **✅ Одобренные** в главном меню
2. Откроется список с пагинацией
3. Доступен поиск: нажмите **🔍 Поиск**

### Редактирование сертификата

1. Нажмите **👁️ Просмотр** на сертификате
2. Откроется форма с полями
3. Редактируйте поля аналогично модерации
4. Доступны дополнительные действия:
   - **📷 Заменить фото**
   - **📜 История замен**
   - **💾 Сохранить изменения**
   - **🗑️ Удалить сертификат**

### Замена фото

1. Нажмите **📷 Заменить фото**
2. Отправьте новое фото
3. Система:
   - Загрузит новое фото на Yandex Disk
   - Переместит старое в `app:/archive/replaced/`
   - Сохранит запись в историю
   - Обновит сертификат
4. Появится подтверждение: "✅ Фото успешно заменено!"

### История замен фото

1. Нажмите **📜 История замен**
2. Откроется список замен:
   ```
   📜 История замен фото для сертификата #123
   
   🕐 03.03.2026 12:30
   👤 Модератор ID: 123456789
   📝 Замена фото модератором
   
   [↩️ Откатить (03.03 12:30)]
   ```
3. Для каждой замены доступна кнопка **↩️ Откатить**

### Откат замены фото

1. В истории замен нажмите **↩️ Откатить**
2. Система:
   - Восстановит старое фото
   - Обновит сертификат
3. Появится подтверждение: "✅ Фото успешно откачено!"

### Удаление сертификата

1. Нажмите **🗑️ Удалить сертификат**
2. Подтвердите действие
3. Сертификат будет удален из базы

## Настройки

### Просмотр настроек

Команда: `/settings`

Показывает:
```
⚙️ Настройки бота

Текущий разделитель: |

Используйте команду:
/setseparator <новый_разделитель>

Например: /setseparator |
```

### Изменение разделителя

Команда: `/setseparator <разделитель>`

Примеры:
- `/setseparator |` - вертикальная черта
- `/setseparator -` - дефис
- `/setseparator /` - слэш

Разделитель используется для парсинга альтернатив в формате:
```
Бренд | Название
```

## Команды

### Основные команды

- `/start` - главное меню
- `/pending` - список ожидающих заявок
- `/settings` - просмотр настроек
- `/setseparator <разделитель>` - изменить разделитель

### Устаревшие команды (для совместимости)

- `/view <ID>` - просмотр заявки
- `/approve <ID>` - одобрить заявку
- `/reject <ID>` - отклонить заявку
- `/review <ID>` - просмотр деталей
- `/setname <ID> <название>` - установить название
- `/setbrand <ID> <бренд>` - установить бренд
- `/setindex <ID> <индекс>` - установить индекс
- `/setalt <ID> <модели>` - установить альтернативы
- `/clearall` - очистить все заявки

## Рабочий процесс

### Типичный процесс модерации

1. **Проверка заявок**
   - Откройте `/pending`
   - Просмотрите список

2. **Модерация заявки**
   - Нажмите "Просмотр"
   - Проверьте фото и данные
   - Отредактируйте поля при необходимости

3. **Обработка альтернатив**
   - Проверьте pending alternatives
   - Удалите неправильные
   - Нажмите "Принять все" для остальных

4. **Одобрение**
   - Нажмите "Одобрить"
   - Обработайте транзитивные альтернативы
   - Подтвердите

5. **Проверка результата**
   - Откройте "Одобренные"
   - Найдите сертификат
   - Проверьте корректность

### Обработка проблемных заявок

**Плохое качество фото:**
1. Отклоните заявку
2. Пользователь получит уведомление
3. Он может подать новую заявку

**Неправильные данные:**
1. Отредактируйте поля
2. Одобрите заявку
3. Данные будут исправлены

**Дубликат:**
1. Проверьте в "Одобренные"
2. Если дубликат - отклоните
3. Если альтернатива - добавьте связь

## Советы

1. **Проверяйте фото**: Убедитесь, что фото четкое и читаемое
2. **Используйте альтернативы**: Добавляйте популярные названия
3. **Транзитивные связи**: Принимайте для лучшей связности
4. **История замен**: Используйте для отката ошибок
5. **Регулярная модерация**: Проверяйте заявки ежедневно

## Устранение неполадок

**Фото не загружается:**
- Проверьте токен Yandex Disk
- Проверьте интернет-соединение
- Попробуйте позже

**Альтернатива не найдена:**
- Проверьте правильность названия
- Убедитесь, что сертификат одобрен
- Добавьте сертификат вручную

**Ошибка при одобрении:**
- Проверьте логи
- Убедитесь, что все поля заполнены
- Попробуйте снова

## Безопасность

1. **Не делитесь токеном админ-бота**
2. **Проверяйте источник заявок**
3. **Регулярно проверяйте одобренные сертификаты**
4. **Используйте историю замен для аудита**
