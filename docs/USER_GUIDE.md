# Blade Guardian - Руководство пользователя

## Начало работы

1. Найдите бота в Telegram: `@YourBotUsername`
2. Нажмите `/start` или кнопку "Start"
3. Откроется главное меню с брендами

## Навигация

### Главное меню

После команды `/start` вы увидите:
- **Сетку брендов** (10×3 кнопки)
- **Кнопку "Ножи без бренда"** (если есть)
- **Пагинацию** (⬅️ 1/5 ➡️) - циклическая, последняя страница → первая
- **🔍 Поиск** - поиск по брендам
- **📤 Загрузить** - загрузить новый сертификат

### Просмотр моделей

1. Нажмите на бренд в главном меню
2. Откроется список моделей этого бренда (10×3 сетка)
3. Доступны:
   - **Пагинация** для большого количества моделей
   - **🔍 Поиск** - поиск по моделям в бренде
   - **🔙 К брендам** - вернуться в главное меню

### Просмотр сертификата

1. Нажмите на модель в списке
2. Откроется сертификат с:
   - **Фото** (если есть)
   - **Информацией**: Бренд - Название - Индекс
   - **Альтернативами** (до 2 кнопок)
   - **Кнопкой "Больше..."** (если альтернатив > 2)
   - **🔙 Назад** - вернуться к списку моделей

### Альтернативные сертификаты

Если у ножа есть альтернативные названия/модели:
1. Нажмите на альтернативу под фото
2. Или нажмите "Больше..." для полного списка
3. В полном списке:
   - Сетка 10×3 с альтернативами
   - Пагинация
   - 🔙 Назад к сертификату

## Поиск

### Поиск по брендам

1. В главном меню нажмите **🔍 Поиск**
2. Введите название бренда (или часть)
3. Главное меню обновится с результатами поиска

### Поиск по моделям

1. В списке моделей нажмите **🔍 Поиск**
2. Введите название модели (или часть)
3. Список обновится с результатами поиска

## Загрузка сертификата

### Способ 1: Только фото

1. Нажмите **📤 Загрузить** в главном меню
2. Прочитайте справку о формате
3. Отправьте фото сертификата
4. Откроется форма редактирования

### Способ 2: Фото с шаблоном

1. Нажмите **📤 Загрузить**
2. Отправьте фото с подписью в формате:
   ```
   Бренд | Название | Индекс
   ```
   Например:
   ```
   Victorinox | Swiss Army Knife | SAK-001
   ```
3. Поля автоматически заполнятся
4. Откроется форма редактирования

### Редактирование формы

После отправки фото откроется форма с кнопками:

**Основные поля:**
- **🏷️ Бренд** - нажмите для изменения
- **📝 Название** - нажмите для изменения
- **🔢 Индекс** - нажмите для изменения

**Альтернативы:**
- **──── Альтернативы ────** - разделитель
- **❌ Название** - удалить альтернативу
- **➕ Добавить альтернативу** - добавить новую

**Действия:**
- **✅ Загрузить** - отправить на модерацию
- **❌ Закрыть** - отменить загрузку

### Добавление альтернатив

1. Нажмите **➕ Добавить альтернативу**
2. Введите в формате: `Бренд | Название`
   Например: `Victorinox | Classic SD`
3. Альтернатива добавится в список
4. Можно добавить несколько альтернатив

### Отправка заявки

1. Заполните все нужные поля
2. Нажмите **✅ Загрузить**
3. Появится сообщение: "✅ Спасибо! Ваша заявка отправлена на модерацию."
4. Сообщение исчезнет через 4.5 секунды
5. Вы вернетесь в главное меню

### Отмена загрузки

1. Нажмите **❌ Закрыть**
2. Подтвердите: **✅ Да** или **❌ Нет**
3. При подтверждении все данные будут потеряны

## Уведомления

После модерации вы получите уведомление:
- **✅ Одобрено**: "Ваша заявка #123 одобрена! Сертификат добавлен в систему."
- **❌ Отклонено**: "Ваша заявка #123 отклонена."

## Советы

1. **Качество фото**: Загружайте четкие фото сертификатов
2. **Названия**: Используйте полные официальные названия
3. **Альтернативы**: Добавляйте популярные альтернативные названия
4. **Поиск**: Используйте поиск для быстрого нахождения нужного ножа
5. **Пагинация**: Листайте страницы для просмотра всех брендов/моделей

## Часто задаваемые вопросы

**Q: Как долго модерируется заявка?**
A: Обычно в течение 24 часов. Вы получите уведомление.

**Q: Можно ли редактировать заявку после отправки?**
A: Нет, но вы можете отправить новую заявку.

**Q: Что делать, если не нашел свой нож?**
A: Используйте поиск или загрузите новый сертификат.

**Q: Обязательно ли заполнять все поля?**
A: Нет, но рекомендуется для лучшей идентификации.

**Q: Можно ли добавить несколько альтернатив?**
A: Да, нажимайте "Добавить альтернативу" несколько раз.
