# Примеры использования

## Сценарий 1: Пользователь создает заявку

### Вариант А: Фото с описанием в подписи

```
Пользователь: [отправляет фото с подписью "Нож охотничий, сталь 95Х18"]

Бот: Загружаю фото на Яндекс.Диск...
Бот: ✅ Заявка успешно создана!
     Путь: /certificates/offer/offer_123456789_20260226_103000.jpg
     Описание: Нож охотничий, сталь 95Х18
```

### Вариант Б: Фото, затем описание

```
Пользователь: [отправляет фото без подписи]

Бот: Загружаю фото на Яндекс.Диск...
Бот: ✅ Фото загружено!
     Теперь отправьте описание или отправьте /skip чтобы пропустить.

Пользователь: Нож охотничий, сталь 95Х18, рукоять из карельской березы

Бот: ✅ Заявка успешно создана с описанием!
```

### Вариант В: Фото без описания

```
Пользователь: [отправляет фото без подписи]

Бот: Загружаю фото на Яндекс.Диск...
Бот: ✅ Фото загружено!
     Теперь отправьте описание или отправьте /skip чтобы пропустить.

Пользователь: /skip

Бот: ✅ Заявка создана без описания!
```

## Сценарий 2: Админ обрабатывает заявки

### Просмотр списка заявок

```
Админ: /pending

Бот: 📋 Заявки на рассмотрении:

     ID: 1
     От: @username
     Описание: Нож охотничий, сталь 95Х18
     Дата: 2026-02-26T10:30:00

     ID: 2
     От: ID 987654321
     Описание: нет
     Дата: 2026-02-26T11:15:00

     Используйте /view <id> для просмотра
```

### Просмотр конкретной заявки

```
Админ: /view 1

Бот: [отправляет фото]
     📋 Заявка #1

     От: @username
     Статус: PENDING

     Описание пользователя:
     Нож охотничий, сталь 95Х18
```

### Добавление описания администратора

```
Админ: /desc 1

Бот: Отправьте новое описание для заявки #1

Админ: Охотничий нож "Медведь"
       Сталь: 95Х18
       Рукоять: карельская береза
       Длина клинка: 120 мм
       Общая длина: 250 мм

Бот: ✅ Описание обновлено для заявки #1
```

### Добавление тегов

```
Админ: /tags 1 охотничий,95х18,береза,медведь

Бот: ✅ Теги добавлены к заявке #1
```

### Просмотр заявки с тегами

```
Админ: /view 1

Бот: [отправляет фото]
     📋 Заявка #1

     От: @username
     Статус: PENDING

     Описание пользователя:
     Нож охотничий, сталь 95Х18

     Описание админа:
     Охотничий нож "Медведь"
     Сталь: 95Х18
     Рукоять: карельская береза
     Длина клинка: 120 мм
     Общая длина: 250 мм

     Теги: #охотничий #95х18 #береза #медведь
```

### Одобрение заявки

```
Админ: /approve 1

Бот: ✅ Заявка #1 одобрена
```

### Отклонение заявки

```
Админ: /reject 2

Бот: ✅ Заявка #2 отклонена
```

## Типичные ошибки и их решения

### Ошибка: "Заявка не найдена"

```
Админ: /view 999

Бот: Заявка не найдена
```

**Решение:** Проверьте ID заявки через `/pending`

### Ошибка: "Ошибка при загрузке фото"

```
Пользователь: [отправляет фото]

Бот: Загружаю фото на Яндекс.Диск...
Бот: ❌ Ошибка при загрузке фото. Попробуйте еще раз.
```

**Возможные причины:**
- Проблемы с токеном Яндекс.Диска
- Нет прав на запись
- Проблемы с сетью

### Ошибка: "Ошибка при получении списка заявок"

```
Админ: /pending

Бот: ❌ Ошибка при получении списка заявок
```

**Возможные причины:**
- Проблемы с подключением к БД
- БД не инициализирована

## Полезные советы

1. **Для пользователей:**
   - Добавляйте подробное описание к фото
   - Указывайте модель, сталь, размеры
   - Делайте качественные фотографии

2. **Для администраторов:**
   - Используйте единый формат описаний
   - Создавайте систему тегов заранее
   - Регулярно проверяйте новые заявки
   - Используйте теги для категоризации

3. **Рекомендуемые теги:**
   - По типу: охотничий, туристический, кухонный, тактический
   - По стали: 95х18, d2, aus8, elmax, m390
   - По материалу рукояти: береза, орех, микарта, g10
   - По производителю: кизляр, нокс, витязь
