# Резюме изменений

## Что было добавлено

Реализована полноценная система заявок на добавление сертификатов в систему BladeGuard.

## Ключевые возможности

### Для пользователей
1. Отправка фото с описанием (или без) для создания заявки
2. Три способа создания заявки:
   - Фото с подписью
   - Фото + текстовое описание
   - Фото без описания
3. Автоматическая загрузка в папку `/certificates/offer`

### Для администраторов
1. Просмотр всех заявок на рассмотрении
2. Детальный просмотр заявки с фото
3. Добавление/редактирование описания
4. Добавление тегов для категоризации
5. Одобрение или отклонение заявок

## Архитектура

### База данных (PostgreSQL)
- `submissions` - заявки пользователей
- `tags` - теги для категоризации
- `submission_tags` - связь заявок и тегов
- `certificates` - одобренные сертификаты
- `certificate_tags` - связь сертификатов и тегов

### Backend (Spring Boot)
- Entity классы для работы с БД
- Repository для доступа к данным
- Service для бизнес-логики
- Миграции через Liquibase

### Боты (Telegram)
- KnifeBot - для пользователей
- AdminBot - для администраторов

### Хранилище (Yandex Disk)
- `/certificates/` - основная папка
- `/certificates/offer/` - заявки пользователей

## Команды ботов

### KnifeBot (пользовательский)
```
/start  - Показать меню
/list   - Список фотографий
/get    - Получить фото
/submit - Создать заявку
/skip   - Пропустить описание
```

### AdminBot (администратор)
```
/start   - Показать меню
/pending - Заявки на рассмотрении
/view    - Просмотреть заявку
/desc    - Изменить описание
/tags    - Добавить теги
/approve - Одобрить заявку
/reject  - Отклонить заявку
```

## Быстрый старт

1. Настройте `.env` файл с токенами
2. Запустите: `docker-compose up -d`
3. Откройте бота в Telegram
4. Отправьте `/start`

Подробнее см. [DEPLOYMENT.md](DEPLOYMENT.md)
